# Alberte Stærmose — Portfolio

A new, independent portfolio built with Vue 3, Vite, Vue Router and CSS. The existing Wix site is the visual/content reference; this repository does not modify Wix.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Next steps

- Replace the clearly marked placeholder content in `src/data/projects.js` with verified Wix content and assets.
- Match the reference layout responsively.
